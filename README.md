# GameParty

Telegram-бот на Go для сбора игровой пати в группах. Профили и подписки отдельные для каждой группы. Лицензия MIT.

## Возможности

- Самостоятельная регистрация, часовые пояса IANA и интересующие игры.
- Каталог популярных игр, добавление игр и алиасы от администратора.
- Сборы на разные игры, кнопка «Участвую» и изменение своей готовности.
- Состав и время в своём или во всех зарегистрированных часовых поясах.
- Приглашение подписчиков игры и ручной пинг всех участников сбора.
- Один сбор на игру на сутки UTC; после 00:00 UTC новый может сосуществовать с предыдущим.
- Истечение через два часа после самой поздней актуальной готовности. Очистка при регистрации.

Полные правила — в [REQUIREMENTS.md](REQUIREMENTS.md). Автоматических уведомлений нет.

## Запуск

Нужны Go версии из `go.mod`, Telegram-бот от [BotFather](https://t.me/BotFather) и постоянная база [Upstash Redis](https://upstash.com/docs/redis/features/restapi) с REST API и токеном записи. Временная файловая система Vercel для хранения данных не используется. Внешних Go-зависимостей нет.

Переменные перечислены в `.env.example`:

| Переменная | Назначение |
| --- | --- |
| `TELEGRAM_BOT_TOKEN` | Токен BotFather |
| `TELEGRAM_WEBHOOK_SECRET` | Случайный секрет, 1–256 символов `A-Z`, `a-z`, `0-9`, `_`, `-` |
| `UPSTASH_REDIS_REST_URL` | HTTPS REST endpoint базы |
| `UPSTASH_REDIS_REST_TOKEN` | Токен базы с правом записи |
| `PORT` | Порт HTTP-сервера, по умолчанию 3000 |

Сервер читает окружение процесса; `.env` автоматически не загружается. Для локального запуска задайте переменные в терминале и выполните:

```powershell
go run ./cmd/server
```

`GET /healthz` — проверка работоспособности HTTP-сервера, `POST /webhook` — Telegram updates. Локальному серверу для Telegram нужен публичный HTTPS tunnel; адрес туннеля передаётся скрипту регистрации webhook.

## Vercel

1. Импортируйте репозиторий в Vercel. В `vercel.json` установлен `framework: go`; точка входа — `cmd/server/main.go`, сервер слушает `PORT`.
2. Создайте постоянную Redis-базу и задайте четыре обязательные переменные окружения в Vercel. Используйте отдельную базу для тестов и production.
3. Выполните deploy. Для `/webhook` должен быть доступен публичный HTTPS URL без страницы авторизации Deployment Protection.
4. В локальном PowerShell задайте тот же токен бота и webhook-секрет в окружении и выполните:

```powershell
./scripts/set-webhook.ps1 -BaseUrl https://your-project.vercel.app
```

Скрипт включает только `message` и `callback_query`, ограничивает подключения Telegram до одного и не удаляет накопленные updates. Один Telegram-бот имеет один webhook: для preview-окружения используйте отдельного бота.

Добавьте бота в группу **администратором**: это нужно для надёжной проверки прав человека через `getChatMember` при назначении алиасов. Лишние права на удаление сообщений и блокировку участников не требуются. Все действия выполняются командами в группе. При включённом privacy mode адресуйте команды явно: `/ready@YourBot cs | 23:00`.

Основано на официальной документации [Go runtime Vercel](https://vercel.com/docs/functions/runtimes/go) и [Telegram Bot API](https://core.telegram.org/bots/api). Vercel Hobby предназначен для личного некоммерческого использования; при монетизации потребуется подходящий тариф или хостинг.

## Пример

```text
/register Europe/Moscow | cs2, Dota 2
/games
/addgame Deep Rock Galactic
/alias Deep Rock Galactic | drg, deep rock
/ready cs | 23:00
```

Бот вернёт карточку с кнопкой «Участвую». Во всех командах используется название или алиас игры:

```text
/join cs
/ready контра | 01:00
/party cs2
/party Counter-Strike 2 | all
/invite cs
/ping cs2
/parties
/profile
/help
```

`/register` также обновляет свой профиль и полностью заменяет список интересов. Пустой список после `|` снимает все подписки. Чужие профили менять нельзя.

`/ready Игра | HH:MM` создаёт сбор текущих суток UTC или меняет вашу готовность в нём. Отдельные будущие даты не принимаются. Время означает ближайшее будущее наступление в вашем поясе: `01:00` после вечера относится к ночному продолжению сессии. Для неоднозначного времени при переводе часов выбирается ближайшее будущее вхождение; несуществующее время отклоняется.

Просмотр, присоединение и пинги используют сегодняшний сбор UTC; если он ещё не создан — продолжающийся активный ночной сбор. После создания нового сбора на ту же игру команды обращаются к новому, а кнопки старой карточки отклоняются. Внутренние ID не нужны пользователю и не показываются.

`/invite Игра` уведомляет зарегистрированных подписчиков игры, `/ping Игра` — всех записавшихся в сбор, включая готовых позже. Обе команды доступны участникам этого сбора. Пинг — упоминания в группе, без личных сообщений; получение push зависит от настроек Telegram получателя.

Алиас не может занять название или алиас другой существующей игры. Объединение уже заведённых разных игр в первой версии не предусмотрено.

Длинные ответы имеют кнопки страниц. Карточки страниц хранятся до 48 часов и являются снимками; актуальное состояние запрашивается повторной командой. Пинги отправляются всеми частями, а не скрываются за страницами.

## Хранение и доставка

На группу хранится JSON-состояние Redis; изменения сохраняются атомарным compare-and-set через Lua. Конкурирующий запрос перечитывает состояние и повторяет изменение. Обработанные update ID сохраняются 48 часов. Завершённый сбор нельзя создать повторно в тех же сутках UTC даже после физической очистки.

Пинги отправляются через `sendMessage` с сохранением прогресса. При временном сбое webhook возвращает 503, и повтор Telegram продолжает отправку. Возможен повтор последней части при сбое между отправкой и сохранением прогресса; при параллельных повторных запросах также возможна повторная доставка. Для этого регистрация webhook ограничивает число соединений одним. Остальные ответы отправляются в теле webhook: Telegram не сообщает серверу результат выполнения такого ответа.

Состояние и снимки ответов хранятся одним ключом на группу: решение рассчитано на небольшие игровые группы. Следите за лимитами базы и API. Не используйте eviction-политику, удаляющую данные при нехватке памяти. Telegram-миграция обычной группы в супергруппу пока не переносит профиль автоматически.

## Проверки

```powershell
go test ./...
go vet ./...
go build ./cmd/server
```

Тесты не обращаются к Telegram и Redis: HTTP API проверяются на локальных тестовых серверах. Настоящий webhook проверяется после настройки секретов и деплоя.
